# MicroBlog Platform

A modern microblogging platform inspired by Twitter/X, built with React, Node.js, and PostgreSQL.

## 🚀 Features

- ✅ **User Authentication** - JWT-based login/register
- ✅ **Create Posts** - Share thoughts with 280 character limit
- ✅ **Edit/Delete Posts** - Full CRUD operations
- ✅ **Like Posts** - Show appreciation for content
- ✅ **Comments** - Threaded comments with replies
- ✅ **User Profiles** - Customizable profiles with bio, location, website
- ✅ **Follow System** - Follow/unfollow other users
- ✅ **Responsive UI** - Mobile-friendly design with TailwindCSS
- ✅ **Real-time Timestamps** - Relative and absolute date display
- ✅ **Post Analytics** - Like and comment counts

## 🛠️ Tech Stack

### Frontend
- React 18 + Next.js 14
- TailwindCSS for styling
- Axios for API calls
- React Hot Toast for notifications
- React Icons for UI icons

### Backend
- Node.js + Express
- PostgreSQL database
- Sequelize ORM
- JWT authentication
- bcrypt for password hashing

### DevOps
- Git version control
- Environment configuration
